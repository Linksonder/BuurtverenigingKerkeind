# Kerkeind

Eenvoudige, responsieve website voor Buurtvereniging Kerkeind in Liempde. Alleen HTML en CSS; geen installatie of build nodig.

## Bekijken en aanpassen

Open `index.html` in je browser. Teksten en links staan in `index.html`, de vormgeving in `style.css` en afbeeldingen in `assets/`.

## GitHub Pages

Push deze bestanden naar je GitHub-repository. Kies bij **Settings → Pages → Deploy from a branch** de gewenste branch en **/(root)**. De site werkt ook onder een repository-subpad dankzij relatieve bestandspaden. Een eigen domein kun je later via Pages instellen; er is nog geen CNAME ingesteld.

Agenda en bestuur verwijzen voorlopig naar de bestaande website. De mailknoppen openen het mailprogramma. Er zijn geen fictieve activiteiten of aanmeldformulieren toegevoegd. Controleer het secretariaatsadres voor ingebruikname.

De fotoverantwoording staat onderaan de pagina. Logo en buurtkaart zijn overgenomen van kerkeind.nu; de kerkfoto is van JHGS (CC BY-SA 3.0 NL).
