# Kerkeind

Eenvoudige, responsieve website voor Buurtvereniging Kerkeind in Liempde. Alleen HTML en CSS; geen installatie of build nodig.

## Bekijken en aanpassen

Open `index.html` in je browser. Teksten en links staan in `index.html`, de vormgeving in `style.css` en afbeeldingen in `assets/`.

## GitHub Pages

Push deze bestanden naar je GitHub-repository. Kies bij **Settings → Pages → Deploy from a branch** de gewenste branch en **/(root)**. De site werkt ook onder een repository-subpad dankzij relatieve bestandspaden. Een eigen domein kun je later via Pages instellen; er is nog geen CNAME ingesteld.

De homepage toont aankomende en afgelopen activiteiten. De actuele activiteiten zijn overgenomen uit de openbare Google-agenda van Kerkeind op 18 november 2026; tijden zijn omgerekend naar Europe/Amsterdam. Dit is bewust statische HTML: de homepage wordt niet automatisch bijgewerkt. Pas bij een nieuwe activiteit datum, jaartal, titel, tijd en de datum in de agendalink samen aan en werk de vermelding ‘bijgewerkt op’ bij. De links openen de oorspronkelijke agenda.

De terugblik bevat Halloween uit de agenda en twee echte fotoalbums uit 2022, duidelijk als archief gemarkeerd. Albumcovers zijn lokaal opgeslagen; de foto’s linken naar de oorspronkelijke verenigingsalbums. Bestuur en verenigingsinformatie verwijzen naar de bestaande website. De mailknoppen openen het mailprogramma.

De fotoverantwoording staat onderaan de pagina. Het oorspronkelijke logo wordt via CSS in één kleur weergegeven; het bronbestand is behouden. Logo en buurtkaart komen van kerkeind.nu. De kerkfoto is van JHGS (CC BY-SA 3.0 NL); de raadhuisfoto van Rosemoon (CC BY-SA 4.0). De kleuren zijn warm baksteenrood, roomwit en olijfgroen. Er is geen JavaScript of buildstap.
